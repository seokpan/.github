# 石나가는 판단

석판팀의 1차 프로젝트 **「石나가는 판단」** 을 위한 GitHub Organization입니다.

On-premise 환경에서 Kubernetes 기반 서비스 플랫폼을 구축하고,  
Ansible 자동화, CI/CD, GitOps, Observability, 장애·복구 검증까지 수행하는 것을 목표로 합니다.

## Repositories

- `seokpan-infra`  
  On-premise 인프라, Ansible 자동화, Kubernetes Bootstrap, 외부 인프라 구성

- `seokpan-app`  
  Frontend, Backend, 게임 로직, 실시간 애플리케이션 서비스

- `seokpan-gitops`  
  Kubernetes Desired State 및 Argo CD 기반 배포 구성

## Collaboration

기본 협업 흐름은 다음과 같습니다.

`Issue → Branch → Commit → Pull Request → Review → Squash Merge`

실제 구현 작업과 변경 이력은 GitHub를 기준으로 관리하며,  
프로젝트 진행 상태는 GitHub Project **「石나가는 판단」** 에서 추적합니다.

## Current Phase

현재 1차 프로젝트 MVP 구현·통합·검증을 진행하고 있습니다.
